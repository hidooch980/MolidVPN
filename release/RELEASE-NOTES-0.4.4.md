# MolidVPN ۰.۴.۴ (ساخت ۳۵) — بروزرسانی چندمنبعی

## تازه
- بررسی بروزرسانی چهار منبع را به ترتیب امتحان می‌کند: raw.githack → statically → jsDelivr → raw.githubusercontent، هر بار با پارامتر یکتا (`?t=…`). اگر یکی جواب نداد یا نسخهٔ قدیمی داد، بعدی امتحان می‌شود.
- بستهٔ جدید هم از همان آینه‌ها دانلود می‌شود و قبل از نصب SHA-256 و امضا بررسی می‌شود؛ فایل‌ها برای هر نسخه نام یکتا دارند تا کش نسخهٔ قبلی تحویل داده نشود.
- اگر «نصب از منابع ناشناس» خاموش باشد، اپ خودش صفحهٔ اجازه را باز می‌کند.

## نکتهٔ صادقانه
CDNها چند دقیقه (معمولاً ۵ تا ۱۵) بعد از انتشار، نسخهٔ شاخهٔ main را تازه می‌کنند. پس اگر همین حالا بعد از انتشار بررسی کنی ممکن است هنوز نسخهٔ قبلی را ببیند؛ بررسی بعدی (یا باز کردن دوبارهٔ اپ) نسخهٔ تازه را می‌آورد.
