# MolidVPN ۰.۴.۱ (ساخت ۳۲) — رفع بروزرسانی + حالت‌های اتصال

## تازه
- **حالت‌های اتصال واقعی**: سه چیپ بالای صفحهٔ خانه حالا کار می‌کنند:
  - «هوشمند»: انتخاب خودکار سرور، پینگ دوره‌ای و تعویض مسیر.
  - «امن»: فقط مسیر انتخابی، بدون تعویض خودکار + کیل‌سوئیچ و DNS امن.
  - «رایگان WARP»: اگر پیکربندی رایگان نباشد می‌سازد، وگرنه همان را فعال می‌کند.
- **بروزرسانی مقاوم به فیلتر**: مانیفست و بستهٔ دانلود حالا اول از CDN (jsDelivr) و بعد از GitHub خوانده می‌شوند، هر دو با بررسی SHA-256 و امضا.
- **اجازهٔ نصب**: اگر «نصب از منابع ناشناس» خاموش باشد، اپ خودش صفحهٔ اجازه را باز می‌کند و پیام می‌دهد.
- پیام‌های خطا گویاتر شدند («دانلود ناموفق»، «اجازهٔ نصب را روشن کن»، …).

## مهم
نسخهٔ ۰.۳.۰ و ۰.۴.۰ فقط آدرس raw.githubusercontent را می‌شناختند که در ایران بلاک است؛ برای همین بروزرسانی خودکار از آن‌ها کار نمی‌کند. **یک‌بار ۰.۴.۱ را دستی نصب کن**؛ از آن به بعد بروزرسانی خودکار (با آینهٔ CDN) کار می‌کند.
