# MolidVPN ۰.۴.۳ (ساخت ۳۴) — بروزرسانی واقعاً کار می‌کند

## چه چیزی درست شد
- **مانیفست و بسته از سه CDN تازه خوانده می‌شوند**: raw.githack، statically و jsDelivr، و در آخر raw.githubusercontent. jsDelivr نسخهٔ `main` را ساعت‌ها کش می‌کرد؛ برای همین ۰.۴.۲ خودش را «آخرین نسخه» می‌دید و بروزرسانی نمی‌شد.
- **حالت اتصال** روی صفحهٔ خانه: اتوماتیک / وارپ (رایگان) / سایفون / تور (Orbot) / شادوساکس و VLESS (نسخهٔ بعد).
- **چیپ‌های هوشمند / امن / رایگان WARP** بالای صفحه واقعی شدند.
- **وارپ رایگان**: ثبت خودکار دستگاه کلادفلر (بدون لینک و اکانت) در تنظیمات ← تونل.
- **اجازهٔ نصب**: اگر «نصب از منابع ناشناس» خاموش باشد، اپ خودش صفحهٔ اجازه را باز می‌کند.
- دانلود با بررسی SHA-256 و امضا، و پیام خطای گویا در هر مرحله.

## نصب
اگر روی ۰.۳.۰ یا ۰.۴.x هستی، **۰.۴.۳ را یک‌بار دستی نصب کن**؛ از آن به بعد دکمهٔ بروزرسانی خودش نسخهٔ تازه را می‌آورد.
