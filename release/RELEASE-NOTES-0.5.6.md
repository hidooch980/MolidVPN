# MolidVPN 0.5.6

بروزرسانی حالا کاملاً لمسی است و تأییدش روی صفحهٔ اصلی دیده می‌شود.

## چه چیزی عوض شد

- هیچ‌چیز خودش نصب نمی‌شود: بعد از دانلود، نصب‌کنندهٔ اندروید باز نمی‌شود. کارت روی صفحهٔ اصلی می‌گوید «نسخهٔ X تأیید شد» و دکمهٔ «نصب» را نشان می‌دهد؛ نصب فقط با لمس همان دکمه شروع می‌شود.
- خبر نسخهٔ تازه دیگر با توست گفته نمی‌شود؛ فقط کارت روی صفحهٔ اصلی می‌ماند.
- دانلود هم فقط با لمس «به‌روزرسانی» شروع می‌شود؛ درصد روی همان کارت می‌آید.
- بعد از تأیید، بسته در حافظهٔ موقت می‌ماند و دکمهٔ «نصب» بدون دانلود مجدد کار می‌کند.

## چه چیزی واقعاً تست شد

- روی دستگاه ۰.۵.۵: کارت «نسخهٔ ۰.۵.۶ آماده است» → لمس → دانلود تا ۱۰۰٪ → تأیید SHA-256 و امضا → کارت به «نسخهٔ ۰.۵.۶ تأیید شد · نصب فقط با لمس خودت» تغییر کرد و **هیچ نصب‌کننده‌ای خودش باز نشد** → لمس «نصب» → دیالوگ اندروید → Update → نسخه ۰.۵.۶ شد.
