# MolidVPN ۰.۴.۵ (ساخت ۳۶) — افزودن از لینک

## تازه
- تنظیمات ← تونل ← **افزودن از لینک**: لینک را بچسبان، بقیه‌اش خودکار.
  - `wg://` یا `wireguard://` یا متن کامل `[Interface]` → همان لحظه پیکربندی WireGuard فعال می‌شود و با لمس دکمهٔ اتصال وصل می‌شوی.
  - `ss://` (هر دو شکل SIP002 و base64)، `vless://`، `vmess://`، `trojan://` → خوانده و ذخیره می‌شوند؛ مبدا، پورت و نام هر کدام نگه داشته می‌شود.
  - آدرس لینک **اشتراک** (`https://…`) → دانلود، باز کردن base64 و خواندن همهٔ لینک‌های داخلش.
- شمارش پروفایل‌های ذخیره‌شده در ردیف «Shadowsocks / VLESS» نمایش داده می‌شود.
- لینک‌ها یکتا ذخیره می‌شوند (وارد کردن دوبارهٔ یک لینک، ردیف تکراری نمی‌سازد).

## محدودیت صادقانه
موتور فعلی فقط WireGuard است. `ss://` و `vless://` و بقیه همین حالا **وصل نمی‌شوند**؛ فقط وارد و ذخیره می‌شوند تا موتور دوم (Xray) بیاید. اتصال شادوساکس/VLESS به یک پشتهٔ TCP/IP در فضای کاربر (tun2socks) یا هستهٔ Xray نیاز دارد؛ آن قدم بعدی است.
